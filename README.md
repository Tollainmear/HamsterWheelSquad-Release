# 鼠鼠蹬蹬队 Windows 客户端

从 [Releases](https://github.com/Tollainmear/HamsterWheelSquad-Release/releases) 下载 `HamsterWheelSquad-版本号-win-release.zip`，解压完整目录并运行 `HamsterWheelSquadPet.exe`。请保留相邻的 `bridge` 文件夹。

本仓库只分发客户端。源码分别维护于 [客户端仓库](https://github.com/Tollainmear/HamsterWheelSquad-Client) 和 [服务端仓库](https://github.com/Tollainmear/HamsterWheelSquad-Server)，源码仓库的访问权限由维护者控制。

桌宠启动时自动在后台检查本仓库的最新正式 Release，设置页也可手动检查。网络检查最多等待 60 秒；失败时可复制弹窗中的错误信息。更新时请下载新包，退出旧客户端后运行新版；不要删除本机账号数据。

首次公开版本：**1.0.0**，Windows x64。软件未做代码签名。
